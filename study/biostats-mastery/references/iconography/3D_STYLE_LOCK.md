# 3D Concept Icon Style Lock

**Reference image:** `references/iconography/3d-style-reference.png`

> Use for concepts that need **3D visualizations** — this is the character proportion and render style, not the flat 2D editorial illustrations.

---

## Relationship to Other Locks

| Lock | File | Style |
|------|------|-------|
| **Flat Editorial** | `STYLE_LOCK.md` | 2D outline + white fill + purple accents |
| **3D Concept** (this file) | `3d-style-reference.png` | 3D rendered, rounded, soft characters |

Use the **color palette** from the Flat Editorial lock (`#A98BFF`, `#7D5CFF`, `#C8B5FF`, `#111111`, `#FFFFFF`) — this 3D style follows the **same palette** but in 3D rendered form.

---

## Character Proportions

- **Overall:** Rounded, chunky, toy-like 3D figures
- **Head:** Oversized relative to body
- **Limbs:** Rounded, simplified — no detailed anatomy
- **Faces:** Simplified features, minimal detail
- **Pose:** Relaxed, approachable

---

## Material & Lighting

| Property | Value |
|----------|-------|
| **Render style** | 3D with soft ambient lighting |
| **Materials** | Soft, slightly glossy — like molded plastic or clay |
| **Shadows** | Subtle, grounded |
| **Perspective** | Isometric or gentle 3D angle |
| **Depth** | Present but understated |

---

## Usage

- Apply when a biostats concept benefits from 3D spatial explanation (e.g. population distributions, risk pyramids, treatment arms in 3D space)
- Use the same purple palette as the flat style for color consistency
- Character proportions here are the canonical "people" style for any 3D visualization

## Style: Minimal Editorial Medical Concept Illustration

| Property | Value |
|----------|-------|
| **Overall** | Clean editorial infographic, conceptual icon illustration, flat vector with subtle depth |
| **Background** | Pure white (`#FFFFFF`) |
| **Composition** | Single centered concept with generous whitespace |
| **Aspect ratio** | 1:1 |
| **Camera** | Orthographic front view |
| **Lighting** | Soft ambient, almost shadowless |

## Usage in Biostats Mastery

- All question icons and concept illustrations must follow this lock.
- Purple accent blocks (`#A98BFF` at 0.45 opacity) go **behind** the main illustration.
- "Micro story" approach: each illustration tells one concept through composition (e.g. one healthy figure + one purple diseased figure + a brace = comparison of disease prevalence).
- Pure white background with generous padding — never busy.

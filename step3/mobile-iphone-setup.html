Scrape CCS QB on iPhone

iPhone Safari has no DevTools console. Use the Userscripts extension (recommended) or a bookmark.

Method A — Userscripts (best)
  1. Install Userscripts from the App Store
  2. iPhone Settings → Safari → Extensions → Userscripts → turn ON
  3. On PC: copy mobile-scrape.user.js to iCloud Drive
  4. Userscripts app → + → import from Files → pick the file
  5. Open qb.ccscases.com → log in → start a block
  6. A blue bar appears at the bottom → tap Scrape 50 (15 min)
  7. JSON downloads to Files → Downloads
Method B — Safari bookmark (after GitHub push)
  1. Push step3/mobile-scrape.user.js to GitHub
  2. Create a bookmark named CCS Scrape
  3. Edit bookmark URL — paste the javascript: line below
  4. On qb.ccscases.com, tap the bookmark
javascript:(function(){var s=document.createElement('script');s.src='https://cdn.jsdelivr.net/gh/stefopps/MeWorld@main/step3/mobile-scrape.user.js';document.head.appendChild(s);})();
While scraping on iPhone
  • Keep Safari open and in foreground
  • Turn off auto-lock (Settings → Display → Auto-Lock → Never) temporarily
  • Text only — no x-ray images (same as ayText on PC)
  • Use Stop if you get errors
  • Wait 30 min if the server blocks you
